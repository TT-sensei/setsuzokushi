# ことむすび

言葉を結ぶ。文をつなぐ。意味が広がる。

「ことむすび」は、接続詞のはたらきを理解し、文と文の関係を考えるための小学生向け学習アプリです。

## 学習のねらい

接続詞の名前を暗記するだけでなく、前の文と後ろの文がどのようにつながっているかを読み取ることを大切にしています。

- 接続詞のはたらきを、意味と例文から知る
- 文脈に合う接続詞を選び、選んだ理由を確かめる
- 似たはたらきの言葉を比べて使い分ける
- 間違えた問題を記録し、あとから特訓する

## 収録している六つのはたらき

1. 順接：だから・そのため・そこで など
2. 逆接：しかし・ところが・それでも など
3. 並列・累加：そして・また・さらに など
4. 対比・選択：一方・それに対して・または など
5. 説明・補足：つまり・なぜなら・たとえば・ただし など
6. 転換：さて・ところで・では など

## 現在の収録問題

初期版は全72問（各はたらき12問）です。問題数を増やす際も、単純な文の入れ替えではなく、文脈の自然さ・正解の妥当性・解説の分かりやすさを確認して追加します。

接続詞は、前後の文や文章全体の文脈によって使い方が変わることがあります。アプリでは、問題文の条件に合うものを選び、なぜその表現が合うのかを解説します。

## 使い方

GitHub Pagesを有効にすると、ブラウザから利用できます。

1. リポジトリの **Settings** を開く
2. **Pages** を開く
3. Build and deployment の Source を **Deploy from a branch** にする
4. Branch を **main**、Folder を **/(root)** にして保存する
5. 公開されたURLからアプリを開く

ローカルで確認する場合は、リポジトリ内の `index.html` をブラウザで開いてください。

## ファイル構成

- `index.html`：アプリの入口
- `css/style.css`：画面デザイン・レイアウト
- `js/app.js`：画面表示、演習、記録、復習の処理
- `js/data.js`：学習内容と問題データ

## 技術方針

- HTML / CSS / JavaScriptによる静的構成
- APIキー・外部API・有料APIなし
- サーバー・データベース・ビルド工程なし
- 学習記録はブラウザの `localStorage` に保存
- 外部フォント・外部画像・外部CDNに依存しない
- タブレットでの利用を優先し、画面幅に応じてレイアウトを調整

学習記録は利用したブラウザ・端末ごとに保存されます。同じ端末でも別のブラウザでは共有されません。ブラウザのサイトデータを消去すると記録も消えます。

## 今後の改善予定

- 問題数の拡充と、学年・難易度の段階づけ
- 接続詞を入れ替えたときに、文の意味や自然さがどう変わるかを比べる問題
- 文章全体を読んで接続詞を選ぶ応用問題
- 問題データの点検と、解説・選択肢の継続的な改善
